## System Overview

### Two Operating Modes

#### Mode 1: OPTIMIZATION (Initial)
```
Status: ACTIVE until 90%+ achieved
Mission: Get all agents to 90%+ win rate
Duration: Runs every 5 minutes continuously
Stops when: All agents at 90%+
Action: Cycles until victory
```

**The Loop:**
```
Phase 1: STANDUP         → Boss assigns tasks
Phase 2: ANALYSIS        → Market analysis
Phase 3: BACKTEST        → Test all 5 agents
Phase 4: OPTIMIZE        → Tune underperformers
Phase 5: EVALUATE        → Check performance
Phase 6: RESEARCH        → Find improvements
Phase 7: CONSENSUS       → Boss decides
Phase 8: TARGET CHECK    → Hit 90%?
                          YES → Victory!
                          NO  → Loop back
```

#### Mode 2: MAINTENANCE (Perpetual)
```
Status: ACTIVE forever after 90%+
Mission: MAINTAIN 90%+ consistency EVERY DAY
Duration: Runs 24/7/365
Never stops because: Success must be protected
Action: Daily checks + auto-recovery
```

**The Protection:**
```
Every Day:
  ✓ End-of-day check (all agents ≥90%)
  ✓ Hourly monitoring (detect trends)
  ✓ Emergency recovery (if degrading)
  ✓ Auto-rollback (restore good params)
  ✓ Daily report (consistency score)

If ANY degradation → IMMEDIATE recovery
Continue until back to 90%+ → Continue monitoring forever
```
